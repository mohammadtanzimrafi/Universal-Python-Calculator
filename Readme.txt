Project Title: Universal Python Calculator.

This project is about developing a comprehensive Universal Python Calculator capable of handling various mathematical and computational tasks. 

"Version 1.0"
Starting with this basic version, the calculator allows users to perform fundamental arithmetic operations.

Features:
1. Interactive Startup: Users can easily initialize the calculator or exit the program with a simple command.
2. Basic Arithmetic Operations: The calculator supports:
    * Addition
    * Subtraction
    * Multiplication
    * Division
3. Dynamic Input Handling: It accepts numerical inputs as floating-point numbers, providing precise calculations.
4. User-Friendly Operation Selection: Operation choices are simplified with intuitive numeric options for ease of use.
5. Error Handling: It notifies users when invalid operations are selected, ensuring a smooth experience.



*** Vision for the Universal Python Calculator ***

This project aims to evolve into a versatile calculator that goes beyond basic operations. 
Features that will introduce soon:
    1. Advanced Mathematical Functions
        * Exponentiation and roots (square root, cube root, etc.)
        * Logarithmic functions (log base 10, natural log, etc.)
        * Trigonometric functions (sin, cos, tan, arcsin, arccos, arctan, etc.)
        * Hyperbolic functions (sinh, cosh, tanh, etc.)
        * Factorials and permutations/combinations
    2. Scientific Computations
        * Complex number arithmetic
        * Matrix operations (addition, subtraction, multiplication, inversion, etc.)
        * Vector operations (dot product, cross product, magnitude, etc.)
        * Linear algebra functions (e.g., eigenvalues, eigenvectors)
        * Solving equations (linear and non-linear)
    3. Statistical Functions
        * Mean, median, mode, and range calculations
        * Standard deviation and variance
        * Probability distributions (normal, binomial, Poisson, etc.)
        * Correlation and regression analysis
    4. Unit Conversions
        * Length, area, and volume
        * Weight and mass
        * Temperature
        * Speed, time, and acceleration
        * Currency conversion (real-time rates using APIs)
    5. Programmable Features
        * Customizable formulas and operations
        * User-defined functions
        * Script execution within the calculator
    6. Graphing Capabilities
        * 2D and 3D graph plotting
        * Graphing equations and inequalities
        * Visualizing data sets
    7. Financial Calculations
        * Loan and mortgage calculations
        * Interest rate computations (simple and compound)
        * Investment growth and ROI calculations
    8. Utility Features
        * History tracking and undo/redo options
        * Save and load calculations
        * Scientific constants (e.g., pi, e, Planck’s constant)
        * Time and date calculations
    9. Multi-Mode Operations
        * Basic mode: For everyday use
        * Scientific mode: For advanced mathematical operations
        * Programmer mode: For binary, octal, and hexadecimal calculations
        * Statistical mode: For data and probability functions
    10. Interactive User Interface
        * Graphical User Interface (GUI) using frameworks like PyQt, Tkinter, or Kivy
        * Voice commands for input
        * Support for keyboard shortcuts
        * Theme customization (dark mode, light mode, etc.)
    11. Extensibility and Customization
        * Plugin support to add more features
        * API integration for advanced use cases (e.g., weather data, stock market stats)
    12. Cross-Platform Compatibility
        * Support for desktop platforms (Windows, macOS, Linux)
        * Mobile support through responsive design or mobile apps
